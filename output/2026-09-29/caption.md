# 데모: 경기 전 확인해야 할 세 가지

> 게시 전 사람 승인 필요

스포츠 카드뉴스는 빠르기만 해서는 안 됩니다. 공식 일정, 공식 발표, 경기 상태를 각각 확인하고 모든 핵심 주장에 원문 링크를 연결하세요. 진행 중 경기는 최종 결과처럼 쓰지 않고, 출처가 충돌하면 제작을 멈춥니다. 이 샘플은 자동 생성 흐름을 보여 주는 데모이며 실제 발행 전에는 당일 정보로 교체하고 종목 담당·팩트체크 담당·편집장의 승인을 받아야 합니다.

## 대체 텍스트

1. 짙은 남색 카드에 경기 전 세 번 확인이라는 제목과 일정, 발표, 상태 확인 안내가 적혀 있다.

2. 공식 일정 원문 링크와 날짜, 시작 시각을 확인하라는 설명 카드다.

3. 공식 발표와 추측을 구분하고 미확정 정보는 확인 중으로 표시하라는 카드다.

4. 경기 상태 다섯 가지와 진행 중 점수를 최종 결과로 쓰지 말라는 안내 카드다.

5. 각 주장과 출처 ID가 선으로 연결되고 출처 충돌 시 발행 중단이라고 적힌 카드다.

6. 종목 담당, 팩트체크와 권리 담당, 편집장의 세 단계 승인 체크박스가 있는 카드다.
