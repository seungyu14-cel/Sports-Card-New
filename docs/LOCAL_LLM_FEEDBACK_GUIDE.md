# 로컬 LLM + Feedback Memory 운영 가이드

## 실행

OpenAI API Key 없이 다음 흐름으로 동작합니다.

MD 파일 → Ollama → 직원별 역할 프롬프트 → 10페이지 카드뉴스 → 직원별 피드백 → SQLite Feedback Memory → 다음 제작에 재사용

권장 명령:

    ollama serve
    ollama pull qwen3:8b

.env:

    OLLAMA_BASE_URL=http://127.0.0.1:11434
    OLLAMA_MODEL=qwen3:8b

웹 실행:

    python -m pip install -e ".[dev]"
    sports-card-news-web --open-browser

로컬 전용 화면:

    http://127.0.0.1:8787/local

## 추천 학습 순서

1. 박지훈 → 이서준 → 한예린: 정확성
2. 종목 데스크 → 리그 기자 → 김도윤: 뉴스 가치
3. 강지우 → 서유진: 문장·흐름
4. 윤서아 → 김서현 → 정하린: 10P 구조·시각화
5. 임현우 → 최지민 → 박소연 → 김동혁: 배포

## Feedback Memory 원칙

좋은 규칙 예시:

- 표지에서 승패를 반복하지 말고 결정적 사건을 첫 15자 안에 배치한다.
- 숫자는 MD 원문에 존재하는 값만 사용하고 단위를 원문과 동일하게 유지한다.
- TOP 이슈는 서로 다른 사건으로 구성하고 같은 장면을 표현만 바꿔 중복시키지 않는다.

저장하면 안 되는 내용:

- 특정 경기의 스코어
- 특정 선수의 당일 기록
- 특정 날짜의 부상 상태

이런 내용은 사실 데이터이지 다음 제작에 재사용할 편집 규칙이 아닙니다.

한 직원당 최근 3개의 learning_rule만 다음 제작 프롬프트에 다시 넣도록 구현되어 있습니다.
